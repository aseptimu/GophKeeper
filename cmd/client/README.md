# GophKeeper Client

Консольный клиент для аутентификации и авторизации пользователей в системе GophKeeper.

## Сборка

```bash
go build -o bin/client ./cmd/client
```

## Использование

### Справка

```bash
./bin/client -help
```

### Регистрация нового пользователя

```bash
./bin/client register <login> <password>
```

Пример:
```bash
./bin/client register john mypassword
```

### Авторизация существующего пользователя

```bash
./bin/client login <login> <password>
```

Пример:
```bash
./bin/client login john mypassword
```

### Настройка сервера

По умолчанию клиент подключается к серверу по адресу `127.0.0.1:8087`. Для изменения адреса используйте флаг `-server`:

```bash
./bin/client -server localhost:8080 login john mypassword
```

## Особенности

- JWT токены автоматически сохраняются в файл `~/.gophkeeper_token`
- Токены имеют права доступа только для владельца файла (0600)
- Клиент корректно обрабатывает ошибки сервера и выводит понятные сообщения
- Поддерживается работа с различными адресами сервера

## Примеры использования

```bash
# Регистрация нового пользователя
./bin/client register alice secret123

# Авторизация
./bin/client login alice secret123

# Работа с другим сервером
./bin/client -server 192.168.1.100:8080 login alice secret123
```

## Обработка ошибок

Клиент обрабатывает следующие типы ошибок:
- Пользователь уже существует (при регистрации)
- Пользователь не найден (при авторизации)
- Неверные учетные данные
- Проблемы с сетью
- Ошибки сервера
